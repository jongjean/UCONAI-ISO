# 15. Reference and Bibliography Management

Date: 2026-05-03
Status: Schema and policy baseline

## Objective

The product must manage reference documents, their permitted AI usage, and bibliography candidates from the start without forcing final bibliography formatting too early.

## Reference Types

| Type | Behavior |
|---|---|
| Normative reference | May be required in Clause 2 |
| Bibliography candidate | Stored for later linkage |
| Background reference | AI may summarize only if permitted |
| Restricted source | Must not be sent to external AI |

## Completion Criteria

- References have permissions and source metadata.
- Bibliography candidates can be linked to document locations later.
- DIS/final stages enforce stricter reference completeness checks.
- Endnote binding plans keep early drafting lightweight and require formal target links after DIS.

## Endnote Binding Strategy

| Stage | Behavior |
|---|---|
| PWI/NP/CD | Record deferred bibliography link intent without forcing final endnote placement |
| DIS | Require reference, target element and note text for formal package readiness |
| FDIS/Publication | Bind endnote targets to stable element keys and export evidence |
