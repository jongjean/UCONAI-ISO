# 11. Edit Ownership and Collaboration

Date: 2026-05-03
Status: Policy baseline

## Objective

Concurrent editing is intentionally blocked for the canonical document. Only one user may hold edit ownership at a time. Other users may add comments, review notes and proposed changes.

## Role Behavior

| Role | Edit behavior |
|---|---|
| Project lead | Can assign or transfer ownership |
| Active editor | Can edit unlocked current document |
| Researcher | Can propose text and add notes |
| Reviewer | Can comment and disposition issues |
| Viewer | Read-only |

## Completion Criteria

- One active lock exists per project/document area.
- Ownership can be transferred with audit.
- Non-editors can still comment without altering canonical text.
